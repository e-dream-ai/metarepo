10

Design Decisions

Why we chose this approach

axiosClient directly (not mutation hooks)
Sequential multi-dream creation in Generate All loop requires imperative control. React Query mutations don't compose well for ordered sequential requests.
deriveTransitions() preserves state
Reordering or adding keyframes shouldn't lose generation results. Existing transitions matched by fromId:toId pair are preserved.
Socket.IO + 10s polling fallback
Primary real-time delivery with a safety net for dropped connections. Matches existing useStudioJobProgress pattern.
onRehydrateStorage reconciliation
No ghost "processing" states after page refresh. Any in-flight state is reset to "failed" so the user can retry cleanly.
No backend changes required
Uses existing /v1/dream CRUD + Socket.IO rooms. The worker already handles Wan I2V and LTX payloads. Zero deployment coordination.
Persist v2 migration
Clean upgrade from Phase 0. Existing localStorage data gets Phase 1 defaults merged in via Zustand persist migrate().
