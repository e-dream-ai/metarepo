Post-meeting update

What changed

Key decisions from our May 13 conversation, now baked into the roadmap.

  • ●Loop mode — checkbox auto-duplicates first keyframe as last, locked and dimmed. Can't botch the loop.
  • ●Preset-driven transitions — start with a preset picker (collapsed), expand for full prompt/model/LoRA control only if needed
  • ●Random seed regeneration — "pull the lever" for a new result. Inline variations deferred to Phase 4.
  • ●Phased rollout — split Phase 1 into Keyframe Strip (Phase 0) and Transition Generation (Phase 1)
  • ●API key config — bring your own keys for OpenAI, Flux, or any OpenAI-compatible endpoint. Encrypted at rest.
  • ●Client-side preview — concat segments in browser for instant playback. Server-side export deferred.
  • ●Prompt templates — repurpose existing action presets. Neural Frames-inspired prompt tips for curation.

Phase 0

Loop Mode

Check the box, get a seamless loop. Uncheck to remove. Can't botch it.

How it works

  • Checkbox in the keyframe strip area
  • Auto-duplicates first keyframe as the last
  • Loop keyframe is visible but locked — dimmed, labeled "Loop"
  • Can't edit, delete, or drag the loop frame
  • Updates automatically when first keyframe changes
  • Unchecking removes the loop frame and its transition

Why this way

  • Pika-style — "if you check loop, you can't screw it up"
  • No sequence errors — the system enforces the constraint
  • Visible so users understand what's happening
  • Bounce looping (A→B→C→B→A) planned as future enhancement

Phase 1

Preset-first settings

Most users pick a preset and go. Power users expand for full control.

Collapsed (default)
  • Preset dropdown + Duration + Generate All
  • One click to start — zero cognitive load
  • Presets from existing action presets (model-scoped)
  • ▾ Customize link to expand
Expanded (on demand)
  • Full prompt text field
  • Model picker (LTX 2.3, Wan I2V)
  • LoRA selection (model-scoped)
  • ▸ Advanced (steps, guidance, CFG)

Same pattern everywhere

Per-transition overrides use the same collapsed/expanded pattern. Click a transition gap → see preset picker → expand to customize. Click a completed result → regenerate with a new random seed, or expand to change settings.
